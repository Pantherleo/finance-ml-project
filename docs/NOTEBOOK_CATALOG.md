## Suggested reading order

Start with fin for acquisition and analysis for data diagnostics. Read the parameterized final.1 cross-asset/ablation notebook to understand the later workflow, then compare selected final.try asset/tuning variants. Inspect model-comparison and earlier asset notebooks as historical alternatives. Filenames such as final, true and corrected do not establish validation.

Some notebooks contain non-forecasting cells; they are retained. The cleanup log describes interrupted/unnamed outputs that are preserved for review. Root originals and exact archived snapshots retain every original code block.
