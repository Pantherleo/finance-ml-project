This changes training protocol and architecture together/across combinations. The result is one recorded run, not evidence of a universally best architecture. The asset-level TCN/Conv1D-LSTM/ConvLSTM-style exports contain further regime results, while the generic optimized tables and tuning folders need careful run attribution.

MAPE units differ between code branches; do not pool a fractional MAPE with a value multiplied by 100. Negative R2 is a possible evaluation outcome, not a saved execution exception. The independent reference metrics have an explicitly different reproducible sample protocol and must not be used to claim model gains without matching test dates.
