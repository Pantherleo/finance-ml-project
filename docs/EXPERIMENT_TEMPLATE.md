# Experiment record

| Field | Required evidence |
| --- | --- |
| Research question | Asset, forecast target and hypothesis |
| Authors/date | Confirmed contributors and actual execution date |
| Source | Code revision, notebook cell IDs and entry point |
| Dataset | Provider, retrieval settings/date, source permissions, checksum and actual coverage |
| Price semantics | Currency, adjustment/contract conventions and OHLC validation |
| Cleaning | Rejected rows, fill policy, duplicates and calendar assumptions |
| Forecast origin | Exact information available and origin/target timestamps |
| Regimes | Explicit dates and definition rationale |
| Split | Train/validation/test boundaries, sample IDs and boundary-label policy |
| Features/targets | Equations, lags, ratio reconstruction and fit scope |
| Model/tuning | Architecture, trial budget, validation criterion and seeds |
| Environment | Exact packages, operating system, hardware and determinism settings |
| Baselines | Identical target dates and information set |
| Results | Units, MAE/RMSE/R2, MAPE definition, variability and failure cases |
| Artifacts | Run ID, immutable paths, hashes and authorized retrieval |
| Reproduction | Fresh-kernel commands, reviewer and observed differences |
